# Аудит реализации

Состояние на ветке после исправлений PR #2 (версия 2.0.0 + исправления).

**Как проверяли.** Прочитан весь код и тесты. Приложение запускалось на
настоящем Tk под Xvfb (Python 3.12, Tk 8.6) с подменой часов, чтобы скорость
была как у живого человека. Каждая проблема ниже воспроизведена скриптом или
скриншотом, если не сказано иное. Для HiDPI использован Xvfb с `-dpi 192`.

**Важность:** высокая — мешает учиться или искажает результат; средняя —
заметно портит опыт; низкая — косметика или техдолг.

Ссылки на задачи — в [ROADMAP.md](../ROADMAP.md).

## Что сделано хорошо

- Нажатие стоит O(1): перекрашиваются 2–3 позиции тегами, а не вся строка.
- В покое нет ни одного таймера, во время теста — один на 200 мс.
- Время берётся с монотонных часов, скорость ограничена сверху.
- Логика отделена от tkinter и проверяется без дисплея; 96 тестов.
- Профиль сохраняется атомарно, повреждённый файл не роняет приложение.

## Ошибки и проблемы

### Исправлено в PR #2

| ID | Проблема | Важность |
|---|---|---|
| A-01 | В минимальном окне (760×560) и при фразе в 3 строки клавиатура срезалась: видно 2 ряда из 4, пропадали подсказки | высокая |
| A-02 | После двойного F6 клавиатура оказывалась под строкой подсказок | средняя |
| A-03 | Строгий режим: ошибка под кареткой не видна — синий фон каретки перекрывал красный | средняя |

### Открытые — логика и метрики

| ID | Проблема | Важность |
|---|---|---|
| A-07 | **Простой считается печатью.** Если бросить фразу и закрыть окно через час, в профиль уходит час «набора», и средняя скорость обваливается. Пауза посреди фразы тоже портит её WPM. | высокая |
| A-08 | **Esc выбрасывает статистику фразы**: ошибки не попадают в слабые клавиши. При этом недобранная фраза при выходе учитывается — поведение несогласованное. | средняя |
| A-14 | **Рекорд WPM общий** для языков и режимов: фраза из урока («рад пора пол») ставит рекорд, недостижимый на обычном тексте. | средняя |
| A-15 | **Ступень урока растёт после одной фразы** с точностью от 96%, скорость не учитывается, понижения нет. F4 с последней ступени перескакивает на первую. | средняя |
| A-16 | На первой ступени реальных слов 7 (ru) и 0 (en), поэтому генерируется набор букв вроде «аопр»; на второй — 26 и 17 слов, частые повторы. | средняя |
| A-17 | Псевдослова: 12% — двухбуквенные обрывки, около 15% совпадают с реальными словами («мой», «day»), хотя режим обещает несуществующие. | низкая |

### Открытые — ввод

| ID | Проблема | Важность |
|---|---|---|
| A-10 | **Неверная раскладка ОС**: с включённой английской раскладкой в русской тренировке каждое нажатие — ошибка, без подсказки. Проверено: «ghbdtn» → 6 ошибок из 6. | высокая |
| A-11 | **Caps Lock**: все нажатия — ошибки, без предупреждения (5 из 5). | высокая |
| A-09 | **Буква ё**: в словаре 20 слов с ё, но на экранной клавиатуре её нет — ни подсветки, ни подсказки пальца. 18 из них дублируются вариантом с «е» («нашел» и «нашёл»); в уроки слова с ё не попадают вовсе. | средняя |
| A-23 | Проверяется только Ctrl: Alt/Cmd + буква печатается в тест. На Windows AltGr = Ctrl+Alt, и символы через AltGr игнорируются (для ru/en не нужны, но помешают новым раскладкам). | низкая |

### Открытые — интерфейс

| ID | Проблема | Важность |
|---|---|---|
| A-04 | **HiDPI (масштаб 200%)**: шрифты масштабируются, а размеры холстов заданы в пикселях. «×8» налезает на «КОМБО», буквы не помещаются в клавиши, чип ступени обрезан. Скриншот: [`audit_hidpi.png`](screenshots/audit_hidpi.png). | высокая |
| A-12 | **F7 сбрасывает всю статистику без подтверждения**, а F7 соседствует с F6 и F8. | высокая |
| A-06 | Справка не модальна: нажатия при открытой справке уходят в тест и запускают таймер; Esc при открытой справке пропускает фразу, а не закрывает справку. | средняя |
| A-13 | Итог фразы виден 1,5 с и исчезает — ошибки не успеть разобрать. | средняя |
| A-24 | Все функции только на F-клавишах: на многих ноутбуках нужен Fn, меню и панели настроек нет — возможности трудно обнаружить. | средняя |
| A-25 | Адаптивный режим работает «вслепую»: какие клавиши слабые, пользователь не видит. | средняя |
| A-26 | Нет истории тестов — хранятся только суммы, прогресс во времени не показать. | средняя |
| A-27 | Тренируются только строчные буквы и пробел: нет заглавных, пунктуации и цифр, хотя на клавиатуре нарисованы «.», «,», «;». | высокая |
| A-05 | Каретка и ошибка на **первом символе строки** «растекаются» влево на ширину отступа от центрирования — так Tk рисует фон при `justify=center`. | средняя |
| A-18 | Клик по приглушённому чипу ступени молча переключает режим на «Уроки» и меняет ступень. | низкая |
| A-19 | Цвет точности расходится с округлением: 96,7% показывается как «97%», но жёлтым; 97,1% — зелёным. | низкая |
| A-20 | Плитки статистики разной ширины (173–204 px) — ширина зависит от длины подписи. | низкая |
| A-21 | Блок с фразой прыгает по вертикали, когда фраза в 1 строку сменяется фразой в 2. | низкая |
| A-22 | Склонения: «4 тест.», «2 ошиб.»; рядом «СЛОВ/МИН» и «РЕКОРД WPM». | низкая |

## Как воспроизвести

Скриншоты в [`docs/screenshots`](screenshots) сняты скриптом
[`tools/screenshots.py`](../tools/screenshots.py):

```bash
xvfb-run -a -s "-screen 0 1280x900x24" python tools/screenshots.py docs/screenshots
```
