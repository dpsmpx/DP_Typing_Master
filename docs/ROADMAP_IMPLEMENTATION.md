# Состояние реализации ROADMAP (кандидат 3.0.0rc1)

**Дата:** 20 ноября 2026 года. Рабочая ветка PR #4 поверх PR #3.

## Этапы 2.3–3.0: программная часть реализована

- SQLite-история, графики WPM и точности, карта ошибок, слабые биграммы,
  анализ результата, дневная цель, серия дней, награды.
- Меню и сочетания, масштаб шрифта, светлая тема (после перезапуска),
  зоны пальцев, звук, призрак скорости рекорда.
- Английская локализация большинства стандартных экранов, подсказок и
  результатов; переключение интерфейса независимо от языка упражнений.
- Украинская, белорусская, Dvorak и Colemak раскладки. Списки UK/BE
  содержат по 1200 словоформ. Источники — [SOURCES.md](../dp_typing/data/SOURCES.md).
- Перенос некоторых UI в combo/stats/keyboard модули.
- Пакеты Windows/Linux/macOS, запуск GUI и тесты на CI.

## Для полной приемки остаются внешние проверки

Реальные многочасовые испытания, SmartScreen и Gatekeeper, раскладки на
реальном физическом оборудовании и вычитка словарей носителями языка
**не выполнены**. В [MANUAL_ACCEPTANCE.md](MANUAL_ACCEPTANCE.md) есть
конкретный протокол и место для доказательств.

CI не эквивалентен длительным физическим испытаниям.
