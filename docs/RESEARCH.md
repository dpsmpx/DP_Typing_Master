# Исследование аналогов

Цель — найти функции, которые реально помогают учиться слепой печати, и
понять, что из них стоит перенести в DP Typing Master с учётом его принципов:
настольное приложение, работа офлайн, только стандартная библиотека Python.

Исследование проведено в октябре 2026 года по открытой документации,
README проектов и обзорам. Часть сведений о закрытых продуктах взята из
вторичных источников — такие места помечены.

## Кого смотрели

| Продукт | Тип | Главная идея |
|---|---|---|
| **keybr.com** | веб, открытый код | Буквы открываются по одной, когда текущие достигли целевой скорости |
| **Monkeytype** | веб, открытый код | Короткие тесты на время/слова, тонкая настройка, подробный разбор результата |
| **TIPP10** | десктоп, GPL, C++/Qt | «Умные» уроки с повтором ошибочных клавиш, гибкая реакция на ошибки |
| **Amphetype** | десктоп, Python/Qt | Свои тексты (книги), генератор уроков по самым медленным словам и триграммам |
| **VerseQ** | десктоп, платный | Незаметная подстройка упражнений под ошибки, курсы с заглавными и знаками |
| **Stamina** | десктоп, бесплатный | Упражнения на произвольный набор букв, звуковое сопровождение |
| **Соло на клавиатуре** | десктоп/веб, платный | Длинный структурированный курс с мотивирующими текстами |
| **Клавогонки** | веб | Соревнования, много режимов и словарей, пользовательские словари |
| **ngram-type, rlytype, TypeQuicker** | веб | Статистика и тренировка по биграммам/триграммам |
| **TypingClub, Ratatype** | веб | Учебная программа, награды и звёзды, предупреждение о неверной раскладке |

## Что умеют и что из этого взять

### keybr.com — прогрессия по скорости каждой клавиши
Начинает с небольшого набора самых частых букв; новая буква добавляется, когда
с текущими достигнута целевая скорость. Целевую скорость пользователь задаёт
сам, сайт показывает прогресс по каждой клавише. Порты алгоритма считают
«уверенность» клавиши как время реакции относительно целевой скорости.

**Взять:** повышать ступень урока не по одной удачной фразе, а когда *каждая*
клавиша ступени набирается достаточно быстро и точно; дать задать целевую
скорость; показывать прогресс по клавишам. Это закрывает A-15 из аудита.

### Monkeytype — короткие тесты и разбор результата
Режимы на время (15/30/60/120 с), на число слов, цитаты, «дзен» и свой текст.
Пунктуация и цифры включаются отдельными переключателями. В результате есть
ритмичность (consistency), разбор символов (верные, неверные, лишние,
пропущенные), личные рекорды отдельно по режимам. Можно выбрать единицу
скорости (WPM/CPM) и включить «каретку темпа», идущую со скоростью рекорда.

**Взять:** тесты на время и на число слов; переключатели «заглавные»,
«пунктуация», «цифры»; рекорды отдельно по языку и режиму; экран результата с
разбором; ритмичность; позже — каретку темпа.

### TIPP10 — открытый настольный аналог
Ошибочные клавиши повторяются чаще (у нас это уже есть — режим «Слабые
клавиши»). Настраиваются длительность урока, реакция на ошибку (блокировать,
пропускать, требовать исправления) и визуальные подсказки. Есть свои тексты,
уроки по стилям (юридические, программирование) и подробная статистика.

**Взять:** длительность урока, свой текст, трекер прогресса. Реакция на
ошибку у нас частично есть (строгий режим).

### Amphetype — свои тексты и n-граммы
Позволяет печатать любимую книгу кусками, хранит статистику по клавишам,
триграммам и словам (по описанию проекта — в SQLite) и генерирует уроки из
самых медленных слов и триграмм.

**Взять:** режим «Свой текст» с загрузкой `.txt` и продолжением с места;
статистику по биграммам; хранение истории в `sqlite3` из стандартной
библиотеки.

### VerseQ, Stamina, «Соло на клавиатуре», Клавогонки
VerseQ подстраивает упражнения под ошибки и в расширенных курсах учит
заглавные буквы и знаки препинания. Stamina ценят за упражнения на любой
выбранный набор букв. Клавогонки — за множество режимов и пользовательские
словари. Сведения в основном из обзоров и отзывов 2007–2022 годов.

**Взять:** ступени курса с заглавными и пунктуацией; урок «свой набор
клавиш»; пользовательские словари (тот же механизм, что и свой текст).

### n-граммные тренажёры (ngram-type, rlytype, TypeQuicker, ClickClack)
Считают скорость и ошибки не только по клавишам, но и по парам и тройкам
символов, рисуют тепловую карту ошибок, строят упражнения из проблемных
сочетаний. Есть русскоязычный форк ngram-type.

**Взять:** учёт биграмм в профиле и их подмешивание в адаптивный режим;
тепловую карту клавиш прямо на экранной клавиатуре.

### TypingClub, Ratatype
Структурированная программа от постановки пальцев, звёзды за урок, награды,
отчёты. Ratatype и KTouch предупреждают, когда раскладка ОС не совпадает с
раскладкой упражнения.

**Взять:** предупреждение о неверной раскладке и о Caps Lock (у нас сейчас
каждое нажатие просто считается ошибкой); лёгкую геймификацию — звёзды за
ступень, дневную цель и серию дней.

## Выводы

1. **Сначала снять источники «необъяснимых» ошибок** — неверная раскладка ОС
   и Caps Lock. Так делают Ratatype и KTouch, а у нас это превращает тренировку
   в 0% точности без объяснения.
2. **Тренировать настоящий текст**: заглавные, знаки, цифры и свой текст.
   Без этого навык не переносится на реальную работу — это главный
   функциональный пробел.
3. **Показывать прогресс**: история, график, тепловая карта. Адаптивный режим
   уже собирает данные, но пользователь их не видит.
4. **Курс по модели keybr** вместо повышения ступени после одной фразы.
5. Онлайн-соревнования (Клавогонки, TypeRacer) не берём: им нужен сервер, а
   приложение задумано автономным.
